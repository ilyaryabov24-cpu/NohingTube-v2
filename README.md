# NothingTube 🎛️

Минималистичный клон YouTube в фирменном стиле **Nothing** (чёрный, точечная
матрица, красный акцент `#D5142B`). Single Page Application на чистом
HTML/CSS/JS, бэкенд — **GitHub REST API** + публичный репозиторий,
сборка APK — **Capacitor**.

> Логика, база данных и загрузка видео живут прямо в GitHub-репозитории.
> Репозиторий = сервер: файлы видео в `/videos/`, все данные в `database.json`.

---

> **Статус: релизная сборка.** Проект уже подключён к реальному бэкенду
> (`MODE: 'live'`) и настроен на репозиторий `ilyaryabov24-cpu/NohingTube-v2`.
> Готовый APK лежит рядом — `NothingTube.apk`.

## ⚡ Быстрый запуск (web)

Из папки `www` запусти статический сервер и открой в браузере:

```bash
cd nothingtube/www
npx serve .
# открой http://localhost:3000
```

Приложение работает в **live**-режиме: лента читает `database.json` с
`raw.githubusercontent.com`, воспроизведение идёт потоково (Range-запросы).
Для записи (загрузка видео, лайки, подписки, новые аккаунты) нужен GitHub-токен.

## 🔌 Настройка токена (важно для записи)

Токен **не хранится в коде** (иначе GitHub отзовёт его при пуше в публичный
репозиторий). Вставь его один раз в приложении:

```
Профиль → ⚙️ Настройки → GitHub-токен → Вставить токен → Сохранить
```

Он сохранится в `localStorage` устройства. Создать токен:
`GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)`
— достаточно прав **`repo`**.

> Просмотр ленты, поиск и воспроизведение работают **без токена**. Токен нужен
> только для публикации видео и изменения базы.

## 🗂️ Структура репозитория (GitHub = сервер)

```
NohingTube-v2/
├── www/               ← веб-приложение (SPA)
│   ├── index.html
│   ├── css/style.css
│   └── js/ (config · store · ui · api · views · app)
├── videos/            ← видеофайлы (по одному commit-у на загрузку)
├── database.json      ← база: пользователи, видео, лайки, подписки
├── capacitor.config.json
└── package.json
```

Web-приложение лежит в `www/` — это `webDir` для Capacitor. Репозиторий
используется как «бэкенд»: база и файлы видео читаются с `raw.githubusercontent.com`.

### Готово ✅

- **Лента** — 20 последних видео (сортировка по дате, DESC).
- **Загрузка** — выбор файла (до 100 МБ), название, публикация.
- **Воспроизведение** — потоковое через `<video>` с `raw.githubusercontent.com`
  (браузер шлёт Range-запросы, файл целиком не скачивается). Обрабатываются
  сетевые ошибки с кнопкой «Повторить».
- **Поиск** — регистронезависимый поиск по названию.
- **Профиль** — видео автора, подписчики, лайки, настройки.

## 📦 Сборка APK (Android)

```bash
# 1. Установи зависимости
npm install

# 2. Добавь платформу Android
npx cap add android

# 3. Синхронизируй веб-файлы в нативный проект
npx cap sync android

# 4. Собери APK
cd android
./gradlew assembleDebug
# APK: android/app/build/outputs/apk/debug/app-debug.apk
```

> На устройстве понадобится сеть (обращение к GitHub API). Если нужно
> разрешить http (кроме https), в `capacitor.config.json` уже включён
> `androidScheme: https` и `cleartext: true`.

## 🗃️ Формат базы данных

`database.json` (расширен по сравнению с каркасом: добавлен `likesBy`,
чтобы лайк считался один раз от каждого пользователя):

```json
{
  "users": {
    "user_nick": {
      "password": "12345",
      "subscribers": ["user2", "user3"]
    }
  },
  "videos": [
    {
      "id": "abc123",
      "title": "Название",
      "author": "user_nick",
      "filePath": "https://raw.githubusercontent.com/OWNER/REPO/main/videos/abc123.mp4",
      "likes": 5,
      "likesBy": ["user2", "user3"],
      "date": "2026-08-07T12:00:00Z"
    }
  ]
}
```

## ⚠️ Ограничения GitHub-подхода

- **Файлы > 50 МБ** GitHub предупреждает, **> 100 МБ** не принимает вообще.
  Загрузка через REST API (base64 в одном commit) реально стабильна до
  ~50–95 МБ. Больше — приложение предупредит и предложит отменить.
- Один `commit` = одно видео. Это **быстро и просто для личного/демо-проекта**,
  но не масштабируется и бьёт по лимиту коммитов при активном использовании.
- `database.json` читается с `raw.githubusercontent.com` (быстро), а пишется
  через API с проверкой `sha` (безопасно от случайной перезаписи).

### Альтернативы на будущее
Если понадобится настоящий «хостинг» больших файлов — можно вместо base64
загружать видео во внешнее хранилище (S3, R2, 0x0.st, catbox) и класть только
ссылку в `database.json`. Код в `js/api.js` легко переключить.

## 🧩 Структура проекта

```
nothingtube/
├── www/                  ← веб-приложение (webDir Capacitor)
│   ├── index.html        ← SPA (все экраны)
│   ├── css/style.css     ← Nothing-дизайн
│   └── js/
│       ├── config.js     ← настройки (MODE, OWNER, REPO, TOKEN)
│       ├── store.js      ← состояние, база, авторизация, лайки/подписки
│       ├── api.js        ← загрузка видео (GitHub base64 / demo)
│       ├── ui.js         ← тосты, модалки, иконки, аватары
│       ├── views.js      ← рендер всех экранов
│       └── app.js        ← роутер, шапка, нижняя навигация
├── videos/               ← видеофайлы (для demo лежит demo-video.mp4)
├── database.json         ← база данных
├── android/              ← нативный проект (генерируется, сборка APK)
├── capacitor.config.json ← конфиг Android
└── package.json
```

Сделано как полноценный SPA: экраны входа, ленты, загрузки, плеера, поиска и
профиля переключаются через простой роутер без перезагрузки страницы.
